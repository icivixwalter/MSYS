# QUERY DI CANCELLAZIONE DATI NELLA TABELLA TMP

## ATTIVITA
La query 
   MSys_TB41_DELETE_Qry01_01_ArchivioTMP
CANCELLO i dati nella tabella MSys_TB41_VISUAL_PAG_MASTER_TMP


## SQL
   
DELETE 
      MSys_TB41_VISUAL_PAG_MASTER_TMP.*,
      "-->" AS TxtChiavi,
      MSys_TB41_VISUAL_PAG_MASTER_TMP.COD_PROGETTO_s AS KeyCOD_PROGETTO_s,
      "-->" AS TxtORDi,
      MSys_TB41_VISUAL_PAG_MASTER_TMP.NRO_OGGETTO_i AS ORD_NRO_OGGETTO_i
   FROM
       MSys_TB41_VISUAL_PAG_MASTER_TMP;
